# NetGuard для Windows

Распакуй архив целиком и запусти NetGuard.exe в корне папки. Установка .NET отдельно не требуется. Windows запросит права администратора для управления правилами сети.

В корне находится единственный EXE для запуска окна. Папка app содержит библиотеки и консольный инструмент восстановления, docs — примечания к версии, licenses — лицензии зависимостей. Не перемещай NetGuard.exe отдельно от остальных файлов.

1. Подключи VPN в TUN-режиме, если используешь сценарий доступа через VPN.
2. Выбери нужный виртуальный адаптер и отметь EXE приложений.
3. Включи наблюдение. После срабатывания сценария доступ остаётся заблокирован до явного принятия подключения или выключения защиты.

Поиск доступен при защите. Для изменения набора защищаемых EXE сначала выключи защиту. Встроенная проверка внешнего IP относится к самому NetGuard, а не к маршруту каждого выбранного приложения.

Крестик скрывает окно в трей. Для полного выхода используй меню значка. Явный выход сохраняет блокировки. Удаление папки само по себе правила не снимает.

## Обновление и восстановление

Перед обновлением полностью выйди из старой версии через трей и распакуй новую версию в отдельную папку. Настройки и журнал хранятся в %LOCALAPPDATA%\NetGuard.

Если графическое окно не открывается, выйди из старого экземпляра NetGuard и открой PowerShell от администратора в папке приложения:

.\app\NetGuard.exe status --app 'C:\Apps\Example.exe'
.\app\NetGuard.exe remove --app 'C:\Apps\Example.exe'
Подставь полный путь именно к нужному EXE. remove снимает все правила NetGuard для этого приложения. CLI оставлена в пакете для такого восстановления.

Библиотеки DLL и папки локализации нужны для запуска. Переноси и удаляй пакет целиком. EXE текущей беты не имеют Authenticode-подписи.
